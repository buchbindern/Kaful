# M7. Understand (+ sensor contract)

## The problem it solved
The legacy pipeline turned a manual into a flat "field schema". Its values had no checked evidence,
sensors and alarm limits counted as fields, and examples on screenshots became specs. M7 replaces it
with the understand phase. The phase reads the ingested documents and produces three typed
artifacts:
- `MachineModel`: the component tree, flow paths and fault modes;
- `SensorContract`: the channels the machine reports as data;
- `UnderstandReport`: what was checked, merged, dropped and downgraded.

Every item carries quotes that code has checked against the raw page text, with a source and a
confidence computed by code.

## What was built
- **Three locked prompts** (all on Haiku):
  - `understand.components` v5;
  - `understand.sensor_channels` v5 (max_tokens 32000);
  - `understand.fault_modes` v3.

  Each is sampled 3 times. Agreement across the samples becomes confidence.
- **Per-prompt contexts:** a prompt gets its documents whole when they fit within 95k tokens, and
  retrieval otherwise. Components and channels come only from machine documents (`kind = manual`).
  Fault modes see every document.
- **Merge** (`helpers/canonical_names`): near-duplicate component ids, channel names and fault-mode
  mechanisms become one item, joined on evidence the run produced, never on the golden labels.
- **Checks in code:**
  - evidence classes `verbatim`, `near`, `in_layer` and `unsupported` (hard rule 4);
  - value roles: an example value is never stored as a spec;
  - a channel shown only in a screenshot exists, but its value is an example;
  - pint units, with `pulse` and other counter units;
  - `unit_status = "not_printed"` instead of a made-up unit;
  - categories on a non-category channel are dropped;
  - items quoted only from reference documents are dropped;
  - channels naming an instance beyond machine.toml `[instances]` are dropped.
- **machine.toml additions:**
  - `[[components]]`: parts the machine has that its documents don't name, source `deployment`;
  - `[instances]`.

  The scorer never credits a declared item.
- **Golden labels and scoring:**
  - labels for eversys, CNC and the air_compressor hold-out, the hold-out's drafted blind;
  - `kaful understand score`, with pre-filled disagreement tables that keep filled cells;
  - fault-mode aliases and `documented = false` rows.
- **Onboarding review:** `kaful understand review` writes a read-only page per run. Failed checks
  come first, then items from lowest confidence up, each quote linked to its page.
  `kaful understand review-apply` turns an engineer's corrections and additions into machine.toml
  declarations.
- **Gateway:**
  - retry validation errors saved to the ledger;
  - retry responses cached at their own hash;
  - reused responses recorded with `source = "reused"`.

## Decisions you made
- **2026-11-05:**
  - sampling is explicit;
  - `[[instrumentation]]` declarations;
  - `Component.parent`;
  - `literature` source;
  - pint.
- **2026-11-06:** value roles; secondary channel roles; one usage clock per machine.
- **2026-11-07 and 08:**
  - whole documents when under 95k tokens;
  - screenshot evidence proves that a channel exists, but its value is only an example (hard rule 4);
  - sudden jams are not fault modes;
  - `documented = false` rows;
  - document roles;
  - per-prompt contexts;
  - fault-mode merge;
  - exit floors with a time-box.
- **2026-11-08 and 09:**
  - declared components, with the scorer never crediting them;
  - `unit_status = "not_printed"`;
  - instances in code;
  - prompt changes are general rules only;
  - the air_compressor hold-out, labelled blind;
  - the minimal onboarding review as the exit item.
- **2026-11-09:**
  - sensor_channels v6 dropped, v5 stays locked; CNC repeated quantities logged as a precision gap;
  - the CNC last iteration, then M7 closes under the time-box;
  - M7b is the first post-M7 item: fault-mode carriers from maintenance schedules, status channels as
    events, and CDV as the next hold-out (air_compressor stops being clean once fixes are judged on it).
