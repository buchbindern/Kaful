# M16. Visualization

## The problem it addressed
The results lived in JSON reports and tables. A professor, an interviewer or a later write-up needs figures, and
figures drawn by hand cannot be traced or reproduced. M16 adds `kaful figures build`. It draws every figure and the
demo report (moved from M15) from saved artifacts only, from a committed spec, and records exactly what each figure
read.

## What was built
- **`kaful figures build [--spec PATH] [--only F3 ...]`** (`kaful/figures/`, not a phase).
  - It reads `docs/figures/figures.toml`: the lineages (named by their evaluate run), the figures, display labels,
    the style and the report.
  - Each figure is written as SVG, PNG and a CSV of exactly the plotted numbers.
  - `figures_manifest.json` lists per figure every file it read (repo-relative path and sha256: 245 for F3, down to
    each sample CSV and truth file), its outputs' sha256, how its unit was chosen, any derivation note, and the
    commit that built it.
  - The code version is read before anything is written, so the build's own outputs never mark the checkout dirty.
- **Truth** is read only in `figures/truth_view.py` (added to the truth guard), through `kaful.scoring.truth` and
  evaluate's own forecast-to-truth pairing. A figure's true RUL is therefore exactly the one calibration scored.
- **Byte-stable output.**
  - SVG text is drawn as paths, with a fixed hash salt and no date or creator. PNGs carry no software tag.
  - Every figure starts from matplotlib's defaults plus the spec style (see Surprises).
  - Tested under two hash seeds.
- **The unit a figure shows is chosen by a stated rule, recorded in the manifest.**
  - `median_abs_log_error` (the approved rule) and `median_abs_log_error_all_issues` (rule B, used for F2, F3 and
    F11, disclosed in their captions).
  - F11 shows every unit, so the chosen one can be judged against the rest.
- **F8 is derived by simulation, not read from a saved artifact** (approved 2026-11-18).
  - The backend simulates the verified twin and ParamSet under the twin's two stored profiles, at the prior medians
    and over 60 prior draws from synthesize's own `draw_unit` (seed in the spec).
  - The manifest records this.
- **The demo report, provisional: to be redesigned later; not the final demo** (Natalie, 2026-11-18, at the merge).
  `docs/figures/demo_report.html` is 3.4 MB, one self-contained page with no external requests.
  It follows the old demo's arc on the new artifacts, in 10 sections: pipeline, grounding, verification, wear,
  tracking, forecasts, calibration and sharpness, what-if, cost, scope.
  - Each figure is embedded as an isolated SVG image, checked against the sha256 the manifest just recorded. A
    figure changed after the build is refused.
  - Tables are read from the artifacts:
    - per machine, every parameter (source, prior, reference) and the life statements that calibrated rates rest on;
    - verification against the legacy baseline;
    - eversys's scope decisions.
  - Manual quotes are cut to one sentence of at most 160 characters (`quote_max_chars`), because the page is
    committed. Sentences end only before a capital letter and never after a known abbreviation.
  - A unit selector shows F3's drawing for every CNC unit, with the rule's unit first.
  - The three EvaluationReport disclaimers appear verbatim.
  - **Review the report before the repository is ever made public.** It quotes the Atlas Copco manual and the ISO
    10816 document, short as the quotes are, and names the machines' documents.
- **The what-if was re-run on the headline lineage** (`3f3046`, offline, $0). The report is byte-identical to M13b's
  (`58ce82`) apart from the run id.

**What the figures show:**
- **The particle filter tracks:** F2, F10.
- **Its 90% intervals hold the truth, but they are wide (F3, F4, F7).**
  - In F3 every interval reaches past the forecast horizon, while the lower bound rises from about 16k to 24k h and
    the median moves toward the true failure time.
  - F11 shows a miss as well (unit_16).
- **Data narrows only the parts an observation reaches (F7).** Life widths fall to 0.16-0.35 of the prior; every
  other part stays near 1.
- **Judged lives carry most of the uncertainty (F6).** Eversys has no manual parameter: its "calibrated" lives rest on
  cleaning intervals declared in machine.toml.
- **Cost (F5):** eversys $0.25-0.29 against $5.96 for the legacy pipeline; CNC $4.34-8.44 against $22.06.
- **What-if (F9):** replacing the filter late barely changes the time to limit on a new machine (medians -3% and
  -1%). Over many cycles it raises the scaling rate by +11% (+1% to +30%), or +8% to +14% if the coupling strength r
  were known.

## Measurements
- `pytest -q`: 903 (M15) → 928 passed, offline; 25 figures tests. They cover:
  - every plotted number equals its source: sample CSVs, calibration's truth, trace and observation files, and the
    evaluation report fields;
  - censored intervals stay open, and an already-failed issue gets true RUL 0;
  - the unit rules, the talk variants and the quote splitting;
  - settings changed before or during a draw never change a byte;
  - figures and the report are byte-identical under hash seeds 0 and 1;
  - the report is self-contained and refuses a stale figure.
- ruff and mypy are clean (338 files; kaful strict).
- A full build takes about 3.7 min, most of it F8 and F8t's 360 simulations. `docs/figures/` is 8.8 MB.
- The what-if re-run took 37 min with 6 workers. The first attempt, on one worker, died with the session after about
  30 CPU-minutes.
- API spend: **$0**. No LLM call.

## The most important files
- `kaful/figures/build.py`: the command, the manifest, and the report's sha checks.
- `kaful/figures/spec.py` and `docs/figures/figures.toml`: the spec models and the committed spec.
- `kaful/figures/truth_view.py`, `select.py`: truth through scoring, and the unit rules.
- `kaful/figures/f3_failure_time.py`: the forecast figure, reused by F11 and the report's selector.
- `kaful/figures/report.py`: the demo report.

## How to see it working
```
python -B -m kaful figures build            # every figure and the report (~4 min)
python -B -m kaful figures build --only F3  # one figure; the report is rebuilt from the others as recorded
open docs/figures/demo_report.html
```

## Surprises
- **ProgPy changes matplotlib's global settings on import.** `progpy.visualize` sets line width 3, font size 14 and
  large labels. F8 imports the backend while drawing, so its first render came out with oversized text. Any figure
  built after it in the same process could have changed bytes.
  - Fix: every figure now starts from matplotlib's defaults plus the spec style, inside a context that restores
    everything.
  - The regression test changes settings before and during a draw. It was run red first.
- **The approved unit rule picked a degenerate F3.** In unit_08 the first bearing fails at about 6,600 h, so three of
  the four issues are "already failed": the particle filter rightly says RUL 0 at each. Rule B was approved instead,
  with its bias stated: 6 of 20 units are still running at the last issue.
- **Only 5 parameters across the three machines carry a quote.** Grounding mostly sits in the life statements that
  calibrated rates rest on, so the report shows those too.
- **A sentence splitter cut "Approx." as a sentence end.** The test was run red first.
- **A commit with two mypy annotation errors** (`87a3de8`, the F9 layout): piping mypy into `tail` hid its exit code.
  The errors were fixed in the next commit, and no figure was built from the flawed one.
