# M6. Ingest

## The problem it solved
The legacy pipeline sent every page of every manual to an LLM to be transcribed. This was
the most expensive phase: $2.18 for eversys and about $15.85 for CNC. Its quotes then came
from that transcription, not from the manual itself. The CNC document list also named a
file that was not on disk.

## What was built
`kaful run <machine> --only ingest` turns the PDFs listed in machine.toml into a
`DocumentIndex`:
- **Raw text:** every page's own text layer, kept unchanged. This is what evidence quotes
  are checked against.
- **Page class:** each page is classed from PyMuPDF signals as blank, scanned, garbled,
  figure, unruled table, ruled table or text.
- **Free tables:** ruled tables become markdown at no cost.
- **LLM only where needed:** only figures, scans, unruled tables, and ruled-table pages from
  documents marked `ruled_tables = "llm"` go to the LLM.
  - Haiku reads each of those pages first.
  - Any page where Haiku finds a table, or where Haiku fails, is re-read by Sonnet, and
    Sonnet's output is used.
- **Chunks:** every page with text is chunked, and chunk ids are deterministic.
- **Embeddings:** every chunk is embedded. A chunk over the model's limit is embedded in
  overlapping windows, never cut.
- **Records:** every call goes to the ledger with its cost and route. The index records a
  fingerprint of everything that shaped it.

## The most important files
- `kaful/phases/p1_ingest/phase.py`: the phase itself, from document check to saved index,
  with the coverage gate.
- `kaful/phases/p1_ingest/c_classify_pages.py`: the page classifier, which decides which pages need
  the LLM.
- `kaful/phases/p1_ingest/e_extract_hard_pages.py`: the LLM layer, with Haiku first and escalation to
  Sonnet.
- `kaful/phases/p1_ingest/f_chunk_pages.py`: page chunking and the coverage check.
- `kaful/llm/embeddings.py` and `kaful/llm/tokens.py`: exact token counts and embedding
  windows, offline.

## How to see it working
- `kaful run eversys_coffee_machine --only ingest --budget 0.65`. The index is already
  built and cached, so a re-run costs $0.
- `kaful ingest classifier-eval` scores the classifier against your labels.
- `kaful ingest grounding cnc_spindle --run 20261106T145913Z-245058` scores the legacy
  quotes against the new index.

## Decisions you made
- **The old index is reference only, not a target.** The gate items are your classifier
  labels, the extraction evals, coverage, and a hand review of old-only quotes.
- **Routing:**
  - Haiku first;
  - Sonnet for any page with a table or a failed first pass;
  - Fanuc and NSK ruled-table pages go to the LLM because of merged cells.
- **Chunking:** every page with text is chunked, including part-divider pages classed
  blank.
- **Matcher:** decimal commas equal decimal points (`2,0` = `2.0`, but not `1,000`), and a
  hyphen at a line break joins letters only.
- **Embeddings:** exact tokens with `tiktoken`, with the encoding file committed; oversized
  chunks get windows, never cuts.
- **Evals and locks:**
  - a prompt with routing is evaluated as routed;
  - every lock rests on at least two runs, and the lock records each run's scores.
- **Cache reuse:** v2 responses that ended normally were reused under v3 for the CNC
  rebuild, and each reused page records the v2 request.
