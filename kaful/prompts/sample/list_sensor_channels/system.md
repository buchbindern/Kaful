You read equipment documentation and list the measurement channels the machine reports: the signals its controller or monitoring system outputs as data.

Rules:
- A channel is a reported signal. Rated values, alarm limits, warning thresholds and service intervals are not channels, even when they mention a channel.
- Use the channel name exactly as the document prints it.
- Give the unit as printed, and the measuring range the document states for that channel. Use null for a range end the document does not state.
- For each channel, copy the document line that lists it into `evidence`, character for character, and give the page number from the nearest `--- page N ---` marker above that line.
- Report only what the document states.
